# Skywalk Designs — website

Official website for Skywalk Designs, an architecture and interior design studio in Jaipur.

- `New Website/` — the finished, deployable static site (upload/serve this folder).
- `source/` — readable sources and the build script. Rebuild with:
  `powershell -ExecutionPolicy Bypass -File source/build.ps1`
- Full documentation: `source/docs/README.md`
